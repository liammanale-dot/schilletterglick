FIELDNOTES — PHYSICS EXAM 2

Open output/Fieldnotes-Physics-Exam-2.html (or the same file in the ZIP) in your web browser. This complete copy works offline and needs no installation.

Included:
• 8 study topics and 48 lessons with worked examples.
• 64 original questions with hints and detailed solutions.
• 40-minute, 16-question mock exams with saved score history and review.
• Topic reading checklists, first-try practice accuracy, and a review queue.
• Searchable formulas and an interactive point-charge field explorer.
• Export and import of your progress.

Progress saves in the browser you use. It does not sync across devices. If your browser blocks local storage for files, the sidebar displays a warning; use Export progress to keep a backup. Opening the site under a different address or browser starts a separate progress record. Import a backup to transfer it.

Reading checkmarks measure review coverage. First-try accuracy counts the first practice answer before a hint, solution, or completed mock exam exposed that question. Practice and mock scores are separate. They do not predict your exam grade. Mock exams draw from the same 64-question bank.

The course sources and past-exam map are listed inside the site. Neither previous Exam 2 tests magnetism, so the separate magnetism equation sheet is excluded; confirm the scope of the upcoming exam with your instructor.

The public/ folder contains the editable website files, including the lesson and question JSON data. To serve the editable site, serve public/ with any static web server. To host it, upload the contents of public/ to a static website host. The complete HTML file can also be hosted alone.

The supplied lecture notes and exam PDFs were used as read-only source material. No original PDFs are included in the website package.
